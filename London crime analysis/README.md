London Crime Data Analysis

Project Overview

This project explores crime patterns across London boroughs using data analysis, statistical modelling and geographical visualisation.

Objectives

- Investigate crime trends across different London boroughs.
- Identify geographical patterns and variations in crime.
- Apply statistical techniques to explore relationships within the data.
- Use polynomial regression to investigate crime trends.

Technologies Used

- Python
- Pandas
- GeoPandas
- Matplotlib
- Seaborn
- Scikit-learn

Methods

The project involves data cleaning, exploratory data analysis, statistical modelling and geospatial mapping.

Skills Demonstrated

- Data manipulation and cleaning
- Statistical analysis
- Predictive modelling
- Data visualisation
- Geospatial analysis

Conclusion

The project demonstrates how mathematical and data science techniques can be combined to investigate real-world problems and communicate meaningful findings.
