Playfair Cipher – Python Implementation

Project Overview

This project implements the Playfair Cipher, a classical encryption technique that encrypts messages using pairs of letters and a 5×5 key square.

Features

- Keyword cleaning and preparation
- Generation of a 5×5 encryption grid
- Message preprocessing
- Separation of repeated letters
- Message padding
- Encryption and decryption functionality

Technologies

- Python
- String manipulation
- Algorithm development
- Pytest for automated testing

Skills Demonstrated

- Python programming
- Algorithmic problem-solving
- Functions and modular programming
- Automated software testing

Learning Outcomes

Developed an understanding of classical cryptography, algorithm implementation and software testing.
